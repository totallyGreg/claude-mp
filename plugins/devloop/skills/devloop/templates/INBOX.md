# {{project}} — Capture Inbox

**This file owns:** raw, untriaged captures — a thought, an annoyance, a bug
seen in use, a half-formed idea. Anything not yet decided on.
**Do not put here:** anything already triaged; triage moves the line out
and deletes it here.

## How this works

**Capture is cheap; triage is deliberate.** An entry can be one sentence,
can be wrong, can duplicate another. The only rule is that it gets written
down while it's in your head: `/capture <text>` in Claude Code, or edit
this file. Each capture is stamped with the branch and SHA it was seen on —
evidence for grouping at triage, not a category.

Triage is the first step of the next planning pass, not something done
mid-session ({{loop}} § Triage).
